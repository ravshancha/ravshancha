# UI action icon GIF assets

- Source: `ui-actions-source.mp4`
- Count: 150 icons
- Canvas: 64 × 64 px
- Playback: 10 FPS, infinite loop
- Format: transparent GIF with a white icon
- Naming: `ui-action-rXX-cXX.gif`

Every animated filename matches the corresponding static PNG in `../static/`.

For the website, load the PNG by default and swap its `src` to the matching GIF on pointer hover or keyboard focus. Keep the PNG for visitors who prefer reduced motion.
