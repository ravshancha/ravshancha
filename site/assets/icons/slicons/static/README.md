# Slicons static PNG assets

- Source: supplied Slicons reference image
- Count: 210 icons
- Grid: 21 rows × 10 columns
- Canvas: 64 × 64 px
- Format: transparent PNG with a black line icon
- Naming: `slicon-rXX-cXX.png`

Rows are numbered from top to bottom and columns from left to right. Use the same row/column names for future animated variants so every static and animated file can be paired directly.

The overview contact sheet is stored one directory above as `overview.png`.
